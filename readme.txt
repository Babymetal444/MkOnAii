# 📱 AI 기반 소상공인 맞춤형 숏폼 콘티 & AR 뷰어 솔루션
> **2026학년도 2학기 "AI데이터기반서비스기획" 중간 과제 및 MVP 프로젝트**  
> 지도교수: 승준황 교수님 | 팀명: 부산 로컬 상권 실증팀 (학번/이름: 황재원)

---

## 💡 1. 서비스 소개 (Service Description)
본 솔루션은 소상공인이 마케팅의 필요성을 절감하면서도 숏폼 제작을 포기하는 핵심 원인인 **'기획 노하우 및 템플릿 부재'**를 해결하기 위한 **AI 기획 자동화 및 AR 촬영 가이드 플랫폼**입니다.

* **핵심 기능:** 업종 및 상품 키워드 입력 ➔ Rule-LLM 하이브리드 엔진을 통한 3초 훅 및 초단위 콘티 자동 파싱 ➔ 스마트폰 카메라 위 3x3 AR 그리드 오버레이 실시간 촬영 가이드
* **기대 효과:** 평균 120분 소요되던 숏폼 기획 시간을 **5분(90% 이상 절감)**으로 단축하고, 행동 유도 심리 파라미터를 적용하여 매장 방문 및 매출 전환율(CVR) 극대화

---

## 🎯 2. 서비스 대상 (Target Customer)
* SNS 마케팅(인스타그램 릴스, 유튜브 쇼츠 등)의 필요성을 느끼나, **전문 기획 인력이 없고 매장 운영으로 시간적·비용적 여유가 없는 골목상권 소상공인 및 1인 자영업자**
* 예비 창업자 및 지역 로컬 리테일 매장 운영자

---

## 🎯 3. 서비스 목적 (Core Value & Goal)
1. **제작 생산성 혁신:** 복잡한 대본 작성 및 연출 구상 과정을 AI 자동 파싱으로 대체하여 진입장벽 소멸
2. **AI 환각(Hallucination) 방지:** 자유 생성형 AI의 오류를 차단하기 위해 검증된 **'업종별 연출 Rule DB'**와 LLM을 결합한 안전한 하이브리드 파싱 구조 구축
3. **마케팅 자생력 확보:** 외주 대행사 비용(월 수십만 원) 없이 사장님 혼자서 고효율 홍보 영상을 무한정 제작할 수 있는 환경 조성

## 🔄 4. 이전 기획(V1) vs 고도화 기획(V2) 비교

| 비교 항목 | 이전 초기 기획 (V1) | 개선 및 고도화 기획 (V2) ★ |
| :--- | :--- | :--- |
| **서비스 정의** | AI 영상 및 막연한 텍스트 대본 자동 생성 | 실물 촬영 지원용 **'3초 몰입 훅 + AR 카메라 그리드 콘티'** |
| **핵심 타겟** | 일반 마케터 및 불특정 다수 사용자 | 기획 역량 및 자본이 부족한 **지역 골목상권 소상공인** |
| **서비스 목적** | 단순 영상 수량 제작 증대 | 기획 시간 90% 절감(5분 완성) 및 **행동 유도 훅을 통한 CVR 극대화** |
| **기술적 타당성** | 순수 LLM 의존 (환각 우려 높음) | **Rule-LLM 하이브리드 파싱 구조** (안정성 확보) |
| **사용자 경험(UX)** | 텍스트 대본만 제공하여 촬영 시 막막함 | **스마트폰 AR 3x3 그리드 & 초단위 자막 오버레이 뷰어** |

## 📱 5. MVP 와이어프레임 & 유저 플로우 (4단계 화면)

1. **화면 ⓪ (앱 메인 홈):** 앱 구동 시 오늘의 로컬 트렌드 추천 및 `[3초 만에 숏폼 콘티 만들기]` 메인 CTA 진입 UI
2. **화면 ① (키워드 입력 UI):** 세부 업종(카페, 음식점 등) 선택 및 홍보 키워드(`#시그니처크림라떼`) 태그 입력 폼
3. **화면 ② (Rule-JSON 파싱 엔진):** 입력된 데이터가 업종별 Rule DB와 매칭되어 타임라인(초), 카메라 앵글, 훅 자막이 담긴 **Structured JSON 데이터**로 정렬되는 백엔드 UI
4. **화면 ③ (AR 카메라 그리드 뷰어):** 스마트폰 카메라 위에서 `REC` 상태 바, `3x3 구도 그리드`, `초단위 타겟 앵글`, `실시간 자막 오버레이`가 연동되는 최종 촬영 UX

---

## 🛠️ 6. 시스템 아키텍처 및 기술 스택
* **Input Layer:** 소상공인 모바일 웹/앱 인터페이스 (업종 선택 및 키워드 입력)
* **Processing Layer (Engine):** Rule-LLM 하이브리드 파싱 엔진 (OpenAI API + 업종별 흥행 심리 Rule DB)
* **Output Layer:** RFC 8259 표준 준수 Structured JSON 타임라인 데이터
* **Interface Layer (UX):** HTML5 WebRTC Camera API + Tailwind CSS 기반 AR 3x3 그리드 오버레이 뷰어

* **1주차 (기획 및 UI 디자인):** Figma 와이어프레임 고정 및 업종별 Rule DB 템플릿 엑셀 정리
* **2주차 (AI 파싱 백엔드):** 키워드 입력 ➔ JSON 콘티 출력 엔진 파이프라인 테스트
* **3주차 (프론트엔드 & AR 뷰어):** 모바일 웹 대시보드 화면 및 그리드 오버레이 연동
* **4주차 (~12월, 통합 및 QA):** 전체 유저 플로우 연결 및 PoC 시연 영상 촬영
